# 🛍️ E-Commerce Website

A dynamic and fully functional E-commerce website built using **Node.js**, **Express**, **MongoDB**, and **EJS**. This project showcases the core functionality of an online store, including user authentication, product browsing, cart management, and order processing.

## 🚀 Features

- User registration and login (authentication)
- Admin panel for product management (CRUD operations)
- Product listing with categories
- Shopping cart functionality
- Checkout and order summary
- Responsive EJS templated frontend
- MongoDB for persistent data storage

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, EJS (Embedded JavaScript Templates)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (via Mongoose)
- **Authentication**: bcrypt,JWT
